Inheritance
When we declare a class and want to reuse
its variables+methods in another class than
use Inheritance concept.

->Inheritance provides reusablitiy of variables and function 
which is already define in base class.

->in inheritance we must have at least 2 classes.

->we have to declare only child class instance/object.

->by using child class instance/object we
can call base+derived class variables+functions.

Types of Inheritance
----------------------
1.single inheritance
In single inheritance we have 1 base and 1 derived class

base class(variable+function)
 |
 |
derived class(variable+function)
========================================

2.Hierarchical Inheritance(one base class and multiple derived classes)
	A (base class)
    /	|  \
   B	C   D..........N

here b,c and d are child classes.


3.Multilevel Inheritance
  A (base class) 
  |
  B (intermediate derived class)
  |
  C (derived class)
  |
  N (Derived classes) 

note :- create object/instance variable of last derived class.

Abstract Class
An abstract class can be considered a blueprint for other classes. 
It allows you to create a set of methods that must be created
within any child classes built from the abstract class. 

A class that contains one or more abstract methods is called an abstract class. 
An abstract method is a method that has a declaration 
but does not have an implementation(defination). 

By default, Python does not provide abstract classes. 
Python comes with a module that provides the base for 
defining Abstract Base classes(ABC) and that module 
name is ABC. 

ABC is a module
abc is a package 

from abc import ABC,abstractmethod

syntax
class base(ABC):=====>abstract class
  #logic or statement
  @abstractmethod
  def functionnm(self):====>abstract function/method
   pass

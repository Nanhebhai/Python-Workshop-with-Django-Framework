3.Data Abstraction
only functionality is visible/accessiable to user but internal
coding(mechanism) is hidden to user is called Data Abstraction.

Users can look at an interface and determine how a machine works, but 
they're unable to see how the machine can actually respond to their 
commands.
exp. computer assembled.

In Python Data Abstraction achieve by abstract class+methods.

types of Inheritance
1.single inheritance
one base class and one derived class.
  base1
    |
  derivedclass


2.multilevel inheritance
base1(methods+variables)
  | 
derived1
  |
derived2
  |
derivedN.....


3.Hierarchical Inheritance
	  base1
       /   |     \ 
derived1  derived2   derived3......N

exp.
 	 Area
           |
circle	square   rectangle

4.multiple inheritance
in multiple inheritance we have multiple
base classes and single derived class.

base1 base2 base3......BaseN
  \	 |   /
    derived1	

5.hybrid inheritance(multilevel+multiple inheritance)
A(base class)
|
B   D(base class)
|
C (c and b both are derived classes)

polymorphism
one name many form(many types)
types of polymorphism
1.overloading
(i)function overloading
when same name function redefine with different-different 
arguments list is called function overloading.

(ii)operator overloading
when same operator perform different-different behaviour is 
called operator overloading.

2.overriding
when same name function define in base+derived
class its called function overriding.
 use super()
